# AR SERVER EQUIPMENT

Русскоязычное приложение для планирования серверных помещений. Геометрия проекта хранится в миллиметрах. WebGL, WebXR и экспорт моделей используют метры.

## Запуск на Windows

Распакуйте архив, откройте PowerShell в папке с `server.mjs` и выполните команду. Нужен Node.js 24 или новее. Устанавливать npm-пакеты не требуется.

```powershell
node server.mjs
```

Откройте [http://localhost:4173](http://localhost:4173). При первом посещении появится гостевой проект «Демонстрационная серверная». Регистрация из гостевой сессии переносит проекты в аккаунт. Папка `data` с базой SQLite и моделями создаётся при запуске.

Проверки сервера, геометрии и форматов моделей запускаются командой `node --test`.

## Работа с проектом

- Кнопка «+» в каталоге включает размещение следующим щелчком по полу. На компьютере карточку можно перетащить. Двери и окна прикрепляются к ближайшей стене.
- Выберите «Переместить» или «Повернуть» и перетащите объект. Точные координаты, углы и габариты доступны в свойствах. Ctrl/⌘ + щелчок позволяет выбрать несколько объектов.
- Панель «Помещение» меняет размеры, материалы, стены, потолок и шаг сетки. Режим «Замер» сохраняет расстояние между двумя точками. Доступны мм, см и м.
- В стойке 19″ выберите начальный юнит и оборудование. Шаг составляет 44,45 мм. Перекрывающиеся позиции блокируются.
- «Проверка проекта» показывает пересечения, выход за границу комнаты и перекрытие настроенных зон доступа. Встроенный каталог содержит демонстрационные размеры. Проверка относится к геометрии, а сертификация по строительным нормам проводится отдельно.
- При конфликте версий можно сохранить копию, экспортировать текущий JSON или открыть свежую версию. Экспорт и история снимков доступны в «Документации». PDF содержит изображение сцены, инвентарь, позиции и предупреждения. Текст PDF растеризован, для обработки данных предназначен JSON.

## Развёртывание с HTTPS

Для телефона используйте адрес экземпляра, доступный с телефона по HTTPS. Для развёртывания через Docker Compose укажите `APP_DOMAIN` в `.env`, направьте DNS домена на сервер, откройте TCP-порты 80 и 443 и выполните:

```sh
docker compose up -d --build
```

Caddy получает сертификат для доступного публичного домена. SQLite и файлы моделей хранятся в томе `projects`. Приложение рассчитано на один экземпляр с постоянным диском. Для резервного копирования остановите приложение и скопируйте весь каталог данных или том.

Для локальной конфигурации скопируйте `.env.example` в `.env` и запустите `node --env-file=.env server.mjs`. При использовании собственного обратного прокси укажите `PUBLIC_ORIGIN`, установите `BEHIND_HTTPS=1` и оставьте порт Node недоступным извне. Для встроенного HTTPS задайте `TLS_CERT` и `TLS_KEY` с путями к PEM-файлам.

| Переменная | Назначение |
| --- | --- |
| `HOST`, `PORT` | Адрес и порт Node. По умолчанию `127.0.0.1:4173`. |
| `DATA_DIR` | Папка базы данных и моделей. |
| `PUBLIC_ORIGIN` | Публичный HTTPS-адрес для проверки источника запросов и ссылок восстановления. |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | Создают администратора при первом запуске. Пароль от 12 символов. Уже зарегистрированный email не повышается автоматически. После создания удалите пароль из окружения. |
| `RECOVERY_WEBHOOK` | HTTPS-адрес сервиса доставки писем. Сервер отправляет POST JSON с полями `email` и `url`. |
| `RECOVERY_SECRET` | Необязательный Bearer-токен сервиса доставки. |

Администратор может назначать роли, создавать и переименовывать категории, загружать GLB и glTF 2.0, заменять модели и редактировать их метаданные. Поддерживаются автономные файлы до 15 МБ с треугольной геометрией и основными цветами материалов. Текстуры, анимации и обязательные расширения glTF не обрабатываются.

## AR на телефоне

1. Нажмите «Открыть AR» → «Получить ссылку и QR». Откройте ссылку на телефоне. Она даёт право просмотра. Для сохранения AR-снимков войдите в аккаунт владельца или откройте ссылку с правом редактирования.
2. На устройстве с WebXR запустите сеанс, наведите камеру на пол и дождитесь маркера. Подтвердите размещение. Контрольный отрезок можно сопоставить с физическим ориентиром. Он не меняет размеры модели.
3. На iPhone отметьте объекты и выберите режим Quick Look. «Вся расстановка» сохраняет расстояния и повороты из проекта. «Перебор объектов» показывает модели по очереди. Для переключения внутри Quick Look используйте ползунок времени или меню вариантов, если оно доступно. Масштабирование двумя пальцами включено по умолчанию, его можно отключить, чтобы сохранить физические размеры. Scene Viewer на Android получает выбранный объект.
4. Для независимой настройки откройте «Камера: пообъектное управление». Разместите несколько моделей, выберите нужную в списке «Размещённые объекты» или нажмите «Изменить объект». Настройте смещение, высоту, дистанцию и размер либо используйте перетаскивание и жест двумя пальцами. Нажмите «Применить к объекту». Режим накладывает модели поверх видеопотока. Распознавание поверхностей и привязка к ним доступны в совместимом нативном AR.
5. «Сохранить результат» сохраняет положения объектов в снимок проекта. Его можно скачать в «Документации» → «Версии проекта». Системные AR-просмотрщики управляют размещением внутри ОС.

Размещение и точность отслеживания следует проверить на целевом смартфоне после HTTPS-развёртывания.
